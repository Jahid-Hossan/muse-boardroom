# 👑 MUSE AI // Executive Boardroom & CEO Command Center

> Orchestrate, command, and lead your **4 Muse AI accounts** from a single unified executive group chat war room.

---

## 🌟 What This Platform Does
Normally, separate AI accounts (whether Meta Muse or muse.ai) operate in isolated browser tabs or sessions with no native way to join them into a shared group chat.

This platform solves that problem completely:
- **You are the CEO**: Every command you issue is treated as an authoritative Executive Directive.
- **Unified Boardroom Group Chat**: All 4 accounts reside in one real-time chat interface.
- **3 Dynamic Command Modes**:
  1. 📣 **Broadcast Mode**: Send one strategic prompt (e.g., *"We are launching our new product line"*); all 4 accounts analyze and respond simultaneously through their specialized domains.
  2. 🔄 **Autonomous Roundtable Mode**: The accounts debate and iterate sequentially (Strategy → Marketing → Tech → Operations) to formulate a consensus executive briefing.
  3. 🎯 **Targeted Directive Mode**: Speak directly to any individual account using `@Muse-1`, `@Muse-2`, etc.
- **Task & Deliverable Tracker**: Keep track of high-priority milestones and action items generated by your team.
- **Meeting Minutes Export**: 1-click download of all boardroom transcripts in Markdown format.

## 🔌 Connecting Your 4 Accounts

Click the **"Manage 4 Accounts"** button in the top navigation bar to configure each account:

1. **Simulation Mode (Default & Active Now)**:
   - Works immediately out of the box with zero setup or API keys required.
   - Generates realistic, context-aware executive analysis aligned with your exact instructions.
2. **Meta Muse API / Model Gateway**:
   - Select `Meta Muse API` or `OpenAI-Compatible Endpoint`.
   - Paste the API Key / Session Token for each individual account.
   - Enter your gateway endpoint URL (e.g., `https://api.meta.com/v1/chat/completions` or your proxy).
3. **muse.ai API**:
   - For video search & hosting accounts, enter your API token and endpoint.
4. **Third-Party / Open-Source Gateways**:
   - Supports Groq, OpenRouter, Ollama, or any standard REST LLM proxy.
